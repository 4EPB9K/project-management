# Фаза 2 — распределение работ Фазы 3

**Команда №23:** Александр Черноусов, Илья Четвергов.  
**Проект:** «Четверть» — внутренняя CRM проката велосипедов, электросамокатов и самокатов.

## Файлы

- `phase-02-calculations.xlsx` — **общая расчётная книга Фаз 2 и 3 (14 листов)**; тот же набор вычислений опубликован в Фазе 3.
- `phase-02-solver.py` — воспроизводимая целочисленная оптимизация и независимая проверка полным перебором.
- `phase-02-report.docx` — постановка задачи, экспертные оценки, ограничения, матрица назначений и вывод.

## Математическая модель

Задачи `T01–T12` — именно **подготовка материалов учебной Фазы 3**, а не разработка самой CRM. Два участника задали модельные оценки трудоёмкости и предпочтений (1–5). Трудоёмкость агрегируется медианой; назначение оптимизируется как MILP, с ограничениями `один основной исполнитель`, `не больше 15 ч каждому`, `не меньше 2 задач каждому`.

**Результат учебного расчёта:** 12 задач, 30 плановых человеко-часов, 15/15 часов, 6/6 задач, оптимум `F*=53`; из `2^12=4096` назначений допустимо 392, максимум единственный.

## Воспроизведение

```bash
python3 -m pip install numpy scipy
python3 phase-02-solver.py
```

Для Excel используйте листы `Ф2_задачи`, `Ф2_часы_эксперты`, `Ф2_предпочтения`, `Ф2_решение`. В остальных листах находится связанная Фаза 3.

> **Статус исходных оценок:** учебные модельные значения; не представлены как независимые заполненные анкеты или фактическое время участников. Перед сдачей команда должна подтвердить или заменить их и пересчитать модель. Фактические даты и часы фиксируются в YouGile.
