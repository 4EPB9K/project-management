## Методика (кратко)

- **Эксперты:** 2 участника команды. Каждый независимо даёт по каждой позиции тройку
  (пессимистичная; ожидаемая; оптимистичная) по шкале 1–9.
- **Нечёткий коллективный TOPSIS:** агрегация троек двух экспертов
  (l = min, m = среднее, u = max), нормализация, взвешивание, расстояния до идеала
  и антиидеала, коэффициент близости CC.
- **Чёткий коллективный МАИ:** каждый эксперт заполняет матрицы парных сравнений по шкале
  Саати (критерии + альтернативы по каждому критерию), проверка CR ≤ 0,1, агрегация
  средним геометрическим, синтез глобальных приоритетов.
- **Анализ:** сравнение рейтингов двух методов, анализ чувствительности к весам (±20%).
