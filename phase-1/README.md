# Фаза 1 — Выбор концепции программного проекта

**Дисциплина:** Проектный менеджмент  
**Команда:** № 23 — Черноусов Александр Максимович, Четвергов Илья Вадимович  
**Выбранная концепция:** **«Четверть» — CRM для проката велосипедов, самокатов и электросамокатов**

## Цель

Сравнить четыре концепции программного продукта по четырём критериям с использованием двух методов многокритериального принятия решений:

1. **Нечёткий коллективный TOPSIS** с трёхточечными оценками $L,M,U$.
2. **Чёткий коллективный метод анализа иерархий (МАИ/AHP)** с попарными сравнениями по шкале Саати.

Результаты обоих методов используются для обоснования выбора концепции для последующих фаз.

## Рассмотренные концепции

| Концепция | Краткое содержание |
|---|---|
| TaskFlow | CRM для задач и рабочих процессов |
| MoneyTrack | Система учёта личных доходов и расходов |
| **Четверть** | CRM для управления парком прокатного лёгкого транспорта, арендами, клиентами и обслуживанием |
| BookEasy | CRM для записи и бронирования услуг |

**Критерии:** реализуемость MVP, практическая полезность, ясность требований, потенциал развития. Во всех случаях более высокая оценка предпочтительнее.

## Результат фазы

| Место | Концепция | TOPSIS (близость $CC$) | МАИ (глобальный вес) |
|---:|---|---:|---:|
| **1** | **Четверть** | **0,779** | **0,342** |
| 2 | TaskFlow | 0,472 | 0,270 |
| 3 | BookEasy | 0,282 | 0,195 |
| 4 | MoneyTrack | 0,213 | 0,193 |

Оба метода дают **одинаковый порядок альтернатив**. По использованному набору исходных оценок выбран проект **«Четверть»**. Он уступает TaskFlow по реализуемости MVP, а BookEasy — по потенциалу развития, но выигрывает благодаря практической полезности и сбалансированному набору характеристик.

### Структура Excel

| Лист | Содержимое |
|---|---|
| `Данные` | Описание 4 концепций, 4 критериев; трёхточечные оценки двух участников для критериев и альтернатив |
| `TOPSIS` | Агрегирование экспертных оценок, нормализация, взвешивание, идеальные решения, расстояния $D^+,D^-$, коэффициент $CC$, места |
| `МАИ` | 5 блоков сравнений: критерии и альтернативы по каждому критерию; индивидуальные и коллективные матрицы, веса, проверка $CR$, итоговый рейтинг |

Основные контрольные значения находятся на листе `TOPSIS` в `A39:E43`, на листе `МАИ` в `A4:C8`; коллективные веса критериев МАИ — `T14:T17`.

## Проверка расчётов

- Рейтинг TOPSIS независимо пересчитан из исходных трёхточечных оценок: значения в Excel совпадают.
- Рейтинг МАИ независимо пересчитан как взвешенная сумма локальных приоритетов: значения совпадают.
- Для пяти коллективных матриц МАИ выполнено требование **$CR < 0{,}10$**; максимум — **0,0169**.
- В книге не выявлено вычислительных ошибок `#REF!`, `#DIV/0!`, `#VALUE!`, `#NAME?` или `#N/A`.

> **Статус исходных оценок.** Заполненная книга содержит **модельные оценки, сформированные в качестве учебного расчётного сценария**, а не подтверждённые независимые ответы участников. В официальном задании LLM разрешено использовать для генерации концепций и критериев, но не вместо экспертного оценивания. Перед формальной сдачей Александр и Илья должны самостоятельно оценить альтернативы и критерии, при необходимости заменить исходные данные и обновить отчёт. Приведённый вывод относится к текущему модельному набору.

## Дальнейшая работа

После утверждения концепции во **2-й фазе** распределяются задачи по выполнению **3-й фазы**; в 3-й фазе проект «Четверть» будет рассмотрен через 10–15 Use Cases, COSMIC и Use Case Points. Учёт исполнителей, периодов и фактически затраченного времени ведётся отдельно в таск-трекере (добавляется после оформления документов).
