## Фазы

| Фаза | Папка | Содержание | Статус |
|---|---|---|---|
| 1. Выбор концепции | [`phase-1/`](phase-1/) | ≥4 концепции и ≥4 критерия, трёхточечные экспертные оценки, нечёткий коллективный TOPSIS, чёткий коллективный МАИ, сравнение и выводы | в работе |
| 2. Распределение работы (мета) | [`phase-2/`](phase-2/) | декомпозиция работ фазы 3, оценки сложности и предпочтений, постановка и решение задачи распределения | — |
| 3. Оценка проекта | [`phase-3/`](phase-3/) | ≥10 Use Cases, COSMIC FP, Use Case Points, коллективная экспертная оценка, выводы о масштабе | — |
| 4. Прогнозирование (мета) | [`phase-4/`](phase-4/) | декомпозиция работ фазы 5, трёхточечные оценки, две модели Монте-Карло, срок с 80% достоверностью | — |
| 5. Планирование | [`phase-5/`](phase-5/) | 20–25 задач, ресурсы, предшествование, эвристики упорядочения, календарный план | — |
| Итоговый отчёт | [`report/`](report/) | отчёт по всем фазам, матрица RACI и обоснование распределения задач | — |

## Организация работы

- Работа каждой фазы декомпозируется на задачи; у каждой задачи — исполнитель, период и чистое время (план/факт).
- Распределение фиксируется в [RACI.md](RACI.md) и в трекере; матрица обновляется после каждой фазы.
- Встречи и изучение материалов тоже учитываются как задачи.
- LLM используется только там, где это разрешено заданием; запросы к LLM сохраняются в материалах фазы.
